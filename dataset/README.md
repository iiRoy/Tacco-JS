# Dataset Provenance and Licensing

## Data Source

The Tacco JS experimental dataset incorporates source programs obtained from [IBM Project CodeNet](https://github.com/IBM/Project_CodeNet), a dataset released by IBM Research containing programming submissions collected from online judging platforms.

The Tacco JS research team performed dataset selection, processing, synthetic code clone generation, and labeling for the purposes of JavaScript code clone classification research.
